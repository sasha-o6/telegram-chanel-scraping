# Telegram Channel Scraper

Цей скрипт автоматично підключається до вашого Telegram-акаунту, перевіряє вказані канали на наявність нових повідомлень та фільтрує їх за ключовими словами. Відібрані повідомлення автоматично пересилаються у вибраний вами чат або канал (наприклад, "Збережене").

## Особливості

- Авторизація користувача через `apiId`, `apiHash` та (опціонально) `StringSession`.
- Моніторинг кількох каналів/чатів одночасно.
- Потужна система фільтрації:
  - `keywords`: слова, хоча б одне з яких має бути в тексті.
  - `keywords2`: додаткові слова, які також мають бути присутніми.
  - `banWords`: слова-виключення (якщо вони є в тексті, повідомлення пропускається).
- Захист від дублікатів (перевіряє, чи не було раніше переслано повідомлення з таким самим посиланням, працює в режимі `prod`).
- Автоматичний періодичний запуск кожні 20 хвилин.

## Вимоги

- **Node.js**
- **Telegram API Credentials** (`apiId` та `apiHash`). Їх можна отримати на сайті [my.telegram.org](https://my.telegram.org).

## Встановлення та налаштування

1. Клонуйте репозиторій або завантажте файли проекту.
2. Встановіть необхідні залежності:

```bash
npm install
```

3. Налаштуйте конфігурацію проекту. У проекті використовується файл `const.js` для отримання налаштувань. Створіть файл `const.js` у корені проекту:

```javascript
module.exports = {
  nodeEnv: 'dev', // Вкажіть 'prod' для увімкнення перевірки на дублікати під час надсилання
  days: 1, // За скільки останніх днів перевіряти повідомлення
  limit: 100, // Ліміт кількості останніх повідомлень з каналу, що будуть перевірені за один раз
  channelToSend: 'me', // Куди пересилати знайдені повідомлення (наприклад 'me' — це "Збережене")
  apiId: 1234567, // Ваш API ID з my.telegram.org
  apiHash: 'ваш_api_hash', // Ваш API Hash
  phoneNumberMe: '+380999999999', // Опціонально: номер телефону для швидшої авторизації
  phoneCodeMe: '', // Опціонально
  stringSessionSTR: '', // Рядок сесії. Спочатку залишайте порожнім
  channels: ['channel_username_1', 'channel_username_2'], // Список каналів для перевірки
  keywords: ['робота', 'вакансія'], // Повідомлення має містити хоча б одне з цих слів
  keywords2: ['київ', 'віддалено'], // ОБОВ'ЯЗКОВО: повідомлення також має містити хоча б одне з цих слів
  banWords: ['без досвіду', 'скам'] // Повідомлення буде пропущено, якщо в ньому є хоч одне з цих слів
}
```

> **Примітка:** У репозиторії також є файл `.env.example`. Якщо ви вирішите використовувати файл `.env` замість хардкоду значень у `const.js`, ви можете встановити пакет `dotenv` (`npm install dotenv`) і налаштувати читання змінних середовища.

## Запуск

Щоб запустити скрипт, виконайте команду:

```bash
node app.js
```

### Авторизація (Перший запуск)
При першому запуску (коли змінна `stringSessionSTR` порожня), скрипт попросить вас ввести у консолі ваш номер телефону та код підтвердження, який прийде вам у додаток Telegram (або SMS). Якщо на акаунті стоїть двофакторна автентифікація (2FA), скрипт попросить ввести пароль.

Після успішної авторизації в консоль буде виведено спеціальний рядок (ваша сесія):
```
Авторизація пройшла успішно!
Поточна сесія: 1BJWap12345...
```
Ви можете скопіювати його та вставити у `const.js` у поле `stringSessionSTR` (або у ваш `.env`). Це дозволить при наступних запусках не вводити код знову, а підключатися автоматично.

## Логіка фільтрації

Повідомлення пересилається до вас, **тільки якщо** виконуються всі наступні умови:
1. Воно було опубліковано не раніше, ніж дозволено параметром `days`.
2. В тексті є **хоча б одне** ключове слово з масиву `keywords`.
3. В тексті є **хоча б одне** ключове слово з масиву `keywords2` (зверніть увагу: масив `keywords2` не може бути порожнім, інакше жодне повідомлення не пройде).
4. В тексті **відсутні** всі слова з масиву `banWords`.

Коли скрипт знайде відповідне повідомлення, він надішле його з інформацією про канал, дату, текст, використані ключові слова та посилання на оригінал.
